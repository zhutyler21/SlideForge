## 使用指南

1. **根据内容类型选择模板**: 分析page.content的逻辑结构,匹配最合适的图表类型
2. **保持一致性**: 同类型页面使用相同的图表风格
3. **信息密度**: 咨询报告要求高密度,每页至少包含1个主图表+1个辅助元素
4. **SCQA映射**:
   - Situation → 现状描述类图表(时间线、对比表)
   - Complication → 问题分析类图表(SWOT、矩阵)
   - Question → 框架类图表(流程图、层级图)
   - Answer → 结论类图表(洞察框、行动建议)
